This bot's help command will give a list of all functionalities included within the bot.

Two lines are to be modified in the main code:-
1. Create a new bot and add the invite link of that bot to code (check the invite command)
2. Copy the bot token to the "bot.run" command (check last line of code)

#NOTE
1. Code won't run if the 2nd point is not fulfilled. Please look through a guide on how to create a bot using the "Discord Developer Portal".
2. Download "ffmpeg" and extract it to use the music playback part of the code.
